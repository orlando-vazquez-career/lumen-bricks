## Como escribimos aca

- Una decision tecnica que sea cara de revertir se registra como
  [ADR](architecture/decisions/). Si no esta escrita, no esta decidida.
- El "por que" vale mas que el "que". El codigo ya dice que hace.
- Los comandos van completos y copiables, con la salida esperada cuando ayuda.
